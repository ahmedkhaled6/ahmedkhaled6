## Featured Projects

### BreatheAir &ndash; Cloud-Native AI Air Quality Platform
Bachelor's thesis project: a full-stack, serverless cloud-native application on AWS that ingests, forecasts, and visualizes real-time air quality data for 550+ cities worldwide. Trained and compared two tree-based forecasting models, implemented a three-layer automated test suite, and optimized for cost and cold-start latency via lazy model loading and Lambda layer packaging.

`Python` `AWS Lambda` `S3` `API Gateway` `DynamoDB` `SageMaker` `React` `scikit-learn`

### Pipes in the Desert &ndash; Turn-Based Strategy Game
A turn-based, graph-based multiplayer strategy game built in Java with Maven, architected around abstract classes and interfaces for extensible object-oriented game logic. Authored formal requirements and test-plan documentation defining input/output test cases for core game mechanics, with Git/GitHub version control throughout.

`Java` `Maven` `OOP` `Git`

### Cloud-Native Image Processing Pipeline &ndash; Kubernetes Microservices Project
A five-service Kubernetes microservices pipeline (imagegrab, resize, grayscale, objectdetect, tag) simulating an ML data pipeline for image preprocessing. Redis handles asynchronous message queuing between services and MinIO provides S3-compatible object storage; infrastructure is deployed as code via AWS CloudFormation with AWS CLI-driven S3 artifact management.

`Python` `Docker` `Kubernetes` `AWS CloudFormation` `Redis` `MinIO`

### AWS Serverless Dictionary Grading Platform
A fully serverless dictionary application on AWS (Lambda, API Gateway, DynamoDB, S3) triggered by data stream events. Includes a CloudFormation template generator that provisions personalized per-student infrastructure with one-click deployment links, plus two Lambda-based grading systems &mdash; one validating JSON config, the other using temporary AWS credentials to inspect live student deployments.

`Python` `AWS Lambda` `API Gateway` `DynamoDB` `S3` `CloudFormation`

### Social Fitness Tracker App &ndash; Android Mobile App
An Android fitness app letting users challenge friends to goals (10,000 steps, 5km runs) and track progress in real time via GPS. Built complex UI flows spanning login, home, challenge lists, detail views, and profile management, plus custom networking to sync challenges and results across local or online networks.

`Java` `Kotlin` `Android` `GPS` `Local Storage`
